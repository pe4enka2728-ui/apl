### Описание работы

В ходе практической работы был создан профиль пользователя.

Реализованы следующие элементы:

- Аватар пользователя и фоновая обложка.
- Личные данные: имя, возраст, специальность.
- Контактная информация: Telegram и Email.
- Горизонтальное меню.
- Галерея из 9 фотографий.
- Вертикальная прокрутка с помощью ScrollView.

### Использованные компоненты

- **ConstraintLayout** — основной контейнер.
- **FrameLayout** — размещение аватара поверх фона.
- **LinearLayout** — персональная информация и меню.
- **GridLayout** — расположение фотографий в сетке.
- **ScrollView** — прокрутка содержимого экрана.

### Результат

Создано приложение с персональным профилем, контактами и прокручиваемой галереей фотографий.
